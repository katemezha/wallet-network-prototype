# Конкурентный анализ: выбор сети при отправке USDT

> **Примечание.** Анализ проводился на основании официальной документации приложений. Проверить флоу в самих приложениях не удалось: с нулевым балансом экран отправки недоступен.

## Сравнение

| Вопрос | Trust Wallet | Tonkeeper | MetaMask | Binance (приложение) | Binance (веб) |
|---|---|---|---|---|---|
| Модель | Сначала актив | Сначала актив | Сначала сеть и токен | Адрес → сеть вручную | Адрес → сеть автоматически |
| Порядок шагов | Токен → адрес → сумма → подтверждение | Страница токена «USDT (TRC20)» → Send | Сеть и токен → адрес → сумма → подтверждение | Монета → адрес → сеть → сумма → экран проверки → повторное подтверждение → 2FA | Монета → адрес → сеть подбирается → подтверждение сети → экран проверки → 2FA |
| Как подписана сеть | — | «USDT (TRC20)» в названии актива | — | Сеть + стандарт (BEP20 = BNB Smart Chain) | Сеть + стандарт |
| Автоопределение сети по адресу | — | — | — | Нет | Да |
| Предупреждения про сеть | — | Только о неподдерживаемых TRON-токенах | — (есть предупреждение о похожих и новых адресах) | «Проверьте, совпадает ли сеть… активы могут быть потеряны» | Отдельный шаг подтверждения сети + то же предупреждение |
| Комиссия | — | TRX не нужен, комиссия списывается из «Battery» | Нужен нативный токен сети | Видна до подтверждения | Видна до подтверждения |

«—» — в документации нет данных.

## Наблюдения

1. Используются три модели выбора сети: сначала актив (Trust Wallet, Tonkeeper), сначала сеть (MetaMask), адрес → сеть (Binance).
2. Автоподбор сети по адресу с отдельным подтверждением уже есть в веб-версии Binance. В приложении Binance его нет.
3. Предупреждения о неверной сети в документации есть только у Binance.
4. Подписи сети со стандартом («USDT (TRC20)», «BEP20 = BNB Smart Chain») используют Tonkeeper и Binance.
5. На форуме Trust Wallet есть обращения пользователей, выбравших не ту сеть.
6. Binance отдельно предупреждает не выбирать сеть по самой низкой комиссии.
