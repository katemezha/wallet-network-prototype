# Карточка гипотезы
 
## Гипотеза
 
| | |
|---|---|
| **Сегмент** | Фрилансеры, которые впервые получили оплату в USDT и должны её перевести |
| **Проблема** *(предположение)* | Не понимают разницы между сетями, выбирают неверную и рискуют потерять деньги |
| **Решение** | Для адресов TRON (`T…`) сеть определяется автоматически; для адресов `0x…` показывается понятное объяснение и выбор |
| **Ожидаемый результат** | Меньше ошибок выбора сети, выше уверенность при отправке |
 
## Метрики
 
| Тип | Метрика |
|---|---|
| **Primary** | % участников, отправивших в верную сеть (задание с `0x…`, первое по порядку) |
| **Secondary** | % верной сети в задании с `T…`; медиана времени на задание; уверенность 1–5; какая версия понятнее |
| **Guardrail** | % участников, подтвердивших неверную сеть после подсказки (слепое подтверждение) |
 
## Критерий успеха
 
Версия B ≥ 80% верных отправок **и** B − A ≥ 30 п.п. (по primary-метрике).
 
Порог задан до теста. Статистической значимости на 10 участниках не будет: результат — сигнал для решения о разработке, а не доказательство.
 
## Версии
 
| | A (контроль) | B (тест) |
|---|---|---|
| Основа | Приложение Binance: адрес → сеть вручную | Веб Binance: адрес → сеть подбирается |
| Список сетей | С лейблами стандартов | С лейблами стандартов |
| Сеть по умолчанию | Нет | Для `T…`: TRON, с подписью «определено по адресу» |
| Подсказки | Общее предупреждение «Убедитесь, что сеть совпадает с сетью получателя» | Модалка для `0x…` (см. ниже) |
 
**Каждое задание проверяет свою часть решения:**
- задание с `0x…` → модалка (primary-метрика);
- задание с `T…` → автоопределение сети (secondary-метрика).
Лейблы есть в обеих версиях, поэтому на результат не влияют.
 
### Модалка в B (адрес `0x…`, при нажатии «Далее»)
 
> **Уточните сеть получателя**
> Этот адрес подходит для нескольких сетей. Если выбрать не ту, деньги могут не дойти.
> Проверьте сообщение получателя — сеть часто пишут так: ERC20, BEP20.
>
> Сейчас выбрано: **{сеть} · {стандарт}**
>
> [Сеть верная, продолжить] [Изменить сеть]
> [Не знаю — уточню у получателя]
 
## Тест
 
- **Участники:** 10 человек, никогда не переводивших USDT (скрининг-вопрос перед тестом).
- **Распределение:** 5 начинают с A, 5 с B; после двух заданий им показывают вторую версию и задают вопрос «что понятнее и почему».
- **Стартовый баланс:** 100 USDT.
- **Задание 1** (сообщение от получателя):
  > Привет! Жду перевод 20 USDT. Адрес: `0x8f3c2b9e41d7a05f6c3b8e2d19a4f07c5e6b1a21`, сеть BEP20
- **Задание 2:**
  > Привет! Жду перевод 30 USDT. Адрес: `TQ8f3vRk2Lm9XpZ4wYcN7bHd5sJtE6ua21`, сеть TRC20
Адреса выдуманные, правильного формата.
 
## Риски и допущения
 
- Нет реальных денег, поэтому участники менее внимательны, чем в жизни.
- Версия A не должна быть искусственно хуже реальных продуктов, иначе B выиграет нечестно. Поэтому A повторяет существующий интерфейс (приложение Binance).
- Эффект обучения: после первого задания участник знает про сети, поэтому primary считается только по первому заданию.
